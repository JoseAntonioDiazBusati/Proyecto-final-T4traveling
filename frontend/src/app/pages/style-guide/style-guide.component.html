Botones

Componente button con 4 variantes, 3 tamaños y estados hover/focus/active/disabled.

Variantes

Primary Button Secondary Button Ghost Button Danger Button 
<app-button variant="primary">Primary Button</app-button>
<app-button variant="secondary">Secondary Button</app-button>
<app-button variant="ghost">Ghost Button</app-button>
<app-button variant="danger">Danger Button</app-button>

Tamaños

Small Medium Large 
<app-button size="sm">Small</app-button>
<app-button size="md">Medium</app-button>
<app-button size="lg">Large</app-button>

Estados

Normal Disabled Hover me! Focus me! 
<app-button [disabled]="true">Disabled</app-button>

Full Width

Full Width Primary Full Width Secondary 
<app-button [fullWidth]="true">Full Width</app-button>

Formularios

Componentes de formulario: input, textarea y select. Todos con estados de error y ayuda.

Form Input

  id="nombre"
  label="Nombre"
  type="text"
  [required]="true"
  helpText="...">
</app-form-input>

Form Textarea

<app-form-textarea
  id="mensaje"
  label="Mensaje"

  [maxLength]="200">
</app-form-textarea>

Form Select

<app-form-select
  id="opcion"

  [required]="true">

Alertas

Componente alert con 4 tipos: success, error, warning, info. Con opción de cerrar.

Tipos de Alertas

La operación se completó exitosamente. Hubo un error al procesar tu solicitud. Esta acción puede tener consecuencias. Procede con precaución. Esta es una alerta informativa para comunicar datos importantes. 
<app-alert type="success" title="Éxito">
  Mensaje de éxito...
</app-alert>

Sin Título

Esta alerta no tiene título, solo el mensaje.

No Dismissible

Esta alerta no se puede cerrar. 
<app-alert [dismissible]="false">...</app-alert>
